## Tell Claude how close to match
In `build.md` section 7 (or in your prompt), write one line per screenshot, for example:
- `tickets-board.png`: copy the column layout and card style, but use our own colours.
- `chat.png`: like this, but with a left sidebar of conversations.

If a screenshot has features you do NOT want, say so. If you have no screenshots, delete this folder's contents and Claude will propose a style for approval.
